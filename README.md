# 🌡️ 서울 지역 기온 데이터 분석

## 📌 소개

서울시 **강북구**와 **영등포구**의 기온 데이터를 활용하여  
Python 기반 데이터 분석 및 시각화를 수행했다.

CSV 형태의 기상 데이터를 자동 처리하여:

- ✅ 일평균 기온 계산
- ✅ 월평균 기온 계산
- ✅ 월최고 / 월최저 기온 계산
- ✅ 연도별 기온 변화 시각화

를 수행하였다.

---

# 📂 데이터 출처

- 기상청 기상자료개방포털
- 초단기실황 데이터 활용

```text
기상청 기상자료개방포털 -> 기상예보 -> 동네예보 -> 초단기실황
```

---

# 🛠️ 사용 기술

| 기술 | 설명 |
|---|---|
| Python | 데이터 처리 및 자동화 |
| Pandas | 데이터 분석 및 전처리 |
| Matplotlib | 데이터 시각화 |
| Glob | 파일 자동 탐색 |

---

# 📐 일평균 기온 계산 공식

한국 기상청 기준에 따라:

```text
03시, 06시, 09시, 12시,
15시, 18시, 21시, 24시
```

총 8회의 기온 데이터를 평균 계산하였다.

## 공식

```math
일평균기온 = (T03 + T06 + T09 + T12 + T15 + T18 + T21 + T24) / 8
```
