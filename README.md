# 🌡️ 서울 지역 기온 데이터 분석

## 소개

서울시 **강북구**와 **영등포구**의 기온 데이터를 활용하여  
Python 기반 데이터 분석 및 시각화를 수행했다.

CSV 형태의 기상 데이터를 자동 처리하여:

- ✅ 일평균 기온 계산
- ✅ 월평균 기온 계산
- ✅ 월최고 / 월최저 기온 계산
- ✅ 연도별 기온 변화 시각화

를 수행하였다.

---

# 🛠️ 사용 기술

| 기술 | 설명 |
|---|---|
| Python | 데이터 처리 및 자동화 |
| Pandas | 데이터 분석 및 전처리 |
| Matplotlib | 데이터 시각화 |
| Glob | 파일 자동 탐색 |
